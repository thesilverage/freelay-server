# Freelay server crate

Relay, but free. See the [repository README](../../README.md),
[operator guide](../../docs/OPERATIONS.md), and
[upstream Relay server](https://github.com/No-Instructions/relay-server).

The executable is `freelay` and the package is `freelay-server`.
The internal Rust library name `relay` and this directory name are retained
as upstream-maintenance seams, not public product branding.
